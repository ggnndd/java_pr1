# Консольный симулятор службы доставки

- Python 3.10+

## Структура

```
delivery/
  models/       сущности предметной области (заказ, клиент, курьер, позиция,
                статус, способы доставки)
  services/     сервис управления заказами и курьерами
  ui/           консольное меню, ввод с проверкой и форматирование вывода
tests/          модульные тесты
main.py         точка входа
```

## Запуск

```
python main.py
```

## Запуск тестов

```
python -m unittest discover -s tests -t .
```
